# Evidence

This directory is the named proof location for verify-uyao. Cleanup deletes `.run/` only. Files here survive teardown.

Layout:

```text
evidence/<path-id>/drive.png
evidence/<path-id>/drive.aria.json
evidence/<path-id>/screenshot.png
evidence/<path-id>/snapshot.aria.json
```

`path-id` matches a file in `../features/`.
