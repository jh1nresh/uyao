# uYao 正式向量圖包 v3

這一版不是點陣圖描邊或放大，而是重新建立的可編輯向量幾何。

## 檔案

- `uyao-logo-primary.svg`：淺色背景的正式橫式 Logo。
- `uyao-logo-mono.svg`：黑白印刷與單色用途。
- `uyao-logo-reverse.svg`：透明背景白色反白版。
- `uyao-logo-reverse-on-green.svg`：深綠背景的反白預覽版。
- `uyao-mark-primary.svg`：彩色純圖標。
- `uyao-mark-mono.svg`：單色純圖標。
- `uyao-mark-reverse.svg`：白色純圖標。
- `uyao-app-icon.svg`：App icon 向量母版。
- `uyao-brand-board-vector.svg`：完整向量品牌展示板。
- `uyao-logo-primary-illustrator.pdf`：Illustrator 可直接開啟的向量 PDF。
- `uyao-brand-board-illustrator.pdf`：完整品牌板的 Illustrator 向量 PDF。

## Illustrator

Adobe Illustrator 可直接開啟這些 SVG。所有文字都已轉成 outline，Logo 主體、膠囊、搜尋圈與訊號線保留獨立群組；開啟後可直接另存為 `.ai`。沒有以改副檔名的方式偽造 AI 檔。
