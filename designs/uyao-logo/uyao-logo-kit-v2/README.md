# Uyao Logo Kit v2

Uyao means 「有藥」: connect a nearby medicine need with pharmacy signals and
pharmacist confirmation without claiming that observed scans are exact stock.

## Included assets

- `uyao-logo.svg`: primary horizontal English lockup, minimum width 120 px
- `uyao-logo-reverse.svg`: white lockup for dark brand surfaces
- `uyao-mark.svg`: standalone verified-green mark
- `uyao-mark-mono.svg`: one-color deep-ink mark
- `uyao-mark-reverse.svg`: white standalone mark
- `uyao-favicon.svg`: white-ground browser icon
- `uyao-favicon-16.png` and `uyao-favicon-32.png`: raster browser fallbacks

## Meaning and use

The open U carries the local search need. The joined Y is a connection point
for search, pharmacy signals, and pharmacist confirmation. It is not a medical
cross, pill, location pin, growth arrow, or guarantee that an item is in stock.

Use the standalone mark below 120 px. Keep clear space equal to one quarter of
the mark width. Do not add gradients, shadows, outlines, containers, or a second
accent color.

## Product lockup

The consumer header uses the mark beside the live Chinese name 「有藥」 for
crisp, accessible text. The vector `Uyao` lockup is the international and
fundraising-facing asset.

## Migration from v1

Replace v1 marks and raster outputs together; do not mix old three-block marks
with the v2 connected mark. Palette and minimum-size rules are unchanged.
