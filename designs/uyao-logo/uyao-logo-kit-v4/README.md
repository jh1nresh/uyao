# uYao 正式向量圖包 v4 — Reference Exact

以使用者提供的 1448 × 1086 品牌板為固定母版，依實際像素座標重建幾何、比例、基線、色彩階調與上下版面。所有文字皆為 outline。

## 色彩

- Deep green: `#0B4431`
- Emerald: `#0C8F51`
- Lime: `#89C840`
- Mint: `#D8E8DA`
- Charcoal: `#2F2F2F`

## Illustrator

Illustrator 可直接開啟 SVG 或向量 PDF，確認後另存為 `.ai`。沒有原始 AI/Bézier 母檔，因此本包是從核准 raster reference 建立的 repository-owned vector master。

## 檔案

- `uyao-logo-primary.svg`：淺色背景正式橫式 Logo。
- `uyao-logo-mono.svg`：單色印刷與文件版本。
- `uyao-logo-reverse.svg`：透明背景反白版。
- `uyao-logo-reverse-on-green.svg`：深綠背景反白預覽。
- `uyao-mark-primary.svg`、`uyao-mark-mono.svg`、`uyao-mark-reverse.svg`：純圖標版本。
- `uyao-app-icon.svg`：App icon 向量母版。
- `uyao-brand-board-vector.svg`：與 1448 × 1086 參考圖對位的完整品牌板。
- `uyao-logo-primary-illustrator.pdf`、`uyao-brand-board-illustrator.pdf`：Illustrator 可直接開啟的純向量 PDF。
